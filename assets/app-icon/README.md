# TSMovie app icon

`filmcraft.svg` is the canonical artwork: a 512-unit full-bleed tile (rx=112) with a blue gradient
(`#2f7de1` to `#0b3f91`), a clapperboard, an amber play button and the TSMOVIE wordmark. The other
files here are renders of it (`packaging/icons.sh`, or any resvg). The file names keep the upstream
`filmcraft` stem so build scripts, the installer and the updater find them unchanged.

`filmcraft.icns` (macOS) was not regenerated and still shows the upstream artwork.
